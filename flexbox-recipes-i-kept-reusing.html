Four Flexbox recipes I kept reusing

WEBPROG · Year 2, Term 2 · 2 min read

Based on: WEBPROG Activity 2, submitted 2026-11-06

Activity 2 was titled Box Model and Flexbox, so Grid, JavaScript and media queries were out. That limit made me find out how far Flexbox goes on its own. These are the four patterns I used on every page.

1. A row that wraps without a media query

On my home page the hero row is display: flex; flex-wrap: wrap; gap: 40px 56px. The text has flex: 1.2 1 420px and the portrait has flex: 1 1 300px, and both have min-width: 0 so a long word cannot push the page wider. When there is no room the two drop onto separate lines, and I never wrote a breakpoint.

.hero-row    { display: flex; flex-wrap: wrap; gap: 40px 56px; }
.hero-copy   { flex: 1.2 1 420px; min-width: 0; }
.hero-visual { flex: 1 1 300px;   min-width: 0; max-width: 420px; }

2. A centred column that does not shrink

A flex child with margin: 0 auto shrinks to the width of its content. Giving it width: 100% and a max-width turned it into a full-width column that stays centred.

3. A footer that stays at the bottom

.page { display: flex; flex-direction: column; min-height: 100vh; }
main  { flex: 1; }

On a short page the footer now sits at the bottom of the screen instead of floating halfway up.

4. Divider lines made from gaps

For the facts card, the parent has gap: 1px over a background in the rule colour, and each cell has its own background. The gaps show through as divider lines and stay correct when the cells wrap onto a second line.

The box model half

box-sizing: border-box on everything keeps padding and border inside the width I set. A negative margin with position: relative let my name card overlap the bottom of the portrait. Without position, the image painted over the card.

What changed in Activity 3

Grid is allowed this time, so this site uses it for every page layout. Flexbox is still the right tool for a single row, like the header and the buttons.
